ALGORITMO EDITORIAL:
- RSS Trends Brasil e RSS oficiais permitidos; YouTube Data API conforme quota, métricas internas.
- Tendências com proveniência, time window real, deduplicação, 0-100 score: aceleração 25, demanda 15, alinhamento 20, originalidade 15, viabilidade visual 10, timing 10, verificação cruzada 5. Penalidade/gate absoluto para claims não verificáveis/copyright/pautas exploratórias.
- 50% tendências, 30% evergreen, 20% oportunidades emergentes enquanto não houver evidência superior.
- Notícia com poucas fontes não se torna verdade por estar em tendência. Uma fonte não deve virar roteiro copiado. Site externo é entrada de dados não confiável; impedir prompt injection e SSRF.
- Comparar versões de hooks em benchmarks editorialmente distintos sem repostagem repetitiva. Registrar data de pesquisa e validade.
