# Support

Framechester is maintained by one person in their spare time. The fastest way to get help is to check these first:

1. **Install, run and configure:** [`docs/WEB_STUDIO.md`](docs/WEB_STUDIO.md) (Studio) and the [README](README.md) (CLI). `cargo run -p framechester-cli -- doctor` tells you what is missing on the machine.
2. **Sources, review and approval:** the "Fontes e revisão" section of [`docs/WEB_STUDIO.md`](docs/WEB_STUDIO.md#fontes-e-revisão).
3. **Visuals, layouts and script styles:** [`docs/GUIA_VISUAL.md`](docs/GUIA_VISUAL.md).
4. **Docker:** [`docs/DOCKER.md`](docs/DOCKER.md).
5. **Social connections:** [`docs/REDES_SOCIAIS_WEB.md`](docs/REDES_SOCIAIS_WEB.md).

Still stuck?

- **Questions:** [GitHub Discussions](https://github.com/prod455/framechester/discussions).
- **Bugs:** a [bug report](https://github.com/prod455/framechester/issues/new?template=bug_report.yml) with the version, the steps and the relevant part of `pipeline_report.json`.
- **Security:** never a public issue; see [SECURITY.md](SECURITY.md).

Never paste tokens, passwords, private paths, personal data or media you do not own.
