# Termos de uso

O Framechester é um software livre (veja [LICENSE](../LICENSE)) que cada pessoa instala e
roda no próprio computador. Estes termos valem para o uso do Framechester e dos aplicativos
que o operador registra nas redes sociais para conectar as próprias contas, como o
aplicativo TikTok ou o cliente OAuth do Google.

## Quem usa

Cada instalação tem **um operador**: a pessoa dona do computador e das contas conectadas.
O Framechester não oferece contas a terceiros, não tem servidor central e não presta
serviço a outros usuários.

## O que o aplicativo faz com as contas conectadas

- Lê informações básicas do perfil e contadores públicos (seguidores, curtidas, vídeos) para
  mostrar o desempenho dos canais do próprio operador.
- Envia vídeos só para as contas do operador, e só quando ele pede ou liga o envio
  automático daquela rede no canal. O envio é não público onde a plataforma permite:
  privado no YouTube, "Somente eu" no TikTok e rascunho de Reel no Facebook. No Instagram,
  cuja API só publica Reels públicos, o envio é público.
- Não publica, comenta, curte, segue nem envia mensagens por conta própria.

## Responsabilidades do operador

- Usar o Framechester só com contas que ele controla.
- Respeitar os termos e as diretrizes de cada plataforma, os direitos autorais e o direito
  de imagem de terceiros nos vídeos que produz.
- Revisar cada vídeo antes de publicar. O Framechester produz rascunhos e não aprova
  conteúdo.

## Garantias

O software é fornecido "no estado em que se encontra", sem garantia de resultado,
audiência, monetização ou elegibilidade em qualquer plataforma, conforme a licença.
